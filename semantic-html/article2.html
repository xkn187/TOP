Was ist HTML?

HTML steht für HyperText Markup Language. Mit HTML definieren wir die Struktur und Bedeutung einer Webseite.

Was bedeutet Semantic HTML?

Semantisches HTML bedeutet, dass wir HTML-Elemente passend zum Inhalt verwenden.

Zum Beispiel verwenden wir article für einen eigenständigen Artikel und section für einen thematischen Abschnitt.

HTML und CSS

HTML beschreibt den Inhalt. CSS bestimmt, wie dieser Inhalt aussieht.

Merke: Ein div hat keine eigene semantische Bedeutung.
